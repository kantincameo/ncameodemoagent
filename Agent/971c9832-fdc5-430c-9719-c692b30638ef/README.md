# TaxPilot client — cloud edition (0.7.0)

The client concierge as a chat agent for one household, reading the same database as the published TaxPilot page. No server. Tell it who you are ("I'm Rohan Mehta, client:c-mehta-0") and ask: where is my return, what do you still need, what did my preparer ask me.

Uploads, signatures and replies with attachments happen in the client app (https://claude.ai/artifact/BP2UExpoTbyKg3RSqxEapD) or the chat edition (https://claude.ai/artifact/RwusfMNDf7S34W9LgcEfx7), where a client can do all of it by message; this agent explains, reminds and hands tax questions to the CPA.
